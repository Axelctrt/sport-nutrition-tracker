# Glossaire

- **AppDatabase** : base Dexie principale contenant les données locales.
- **Agrégat** : ensemble synchronisé atomiquement, par exemple une séance et
  ses exercices/séries.
- **Baseline logique** : état de référence utilisé pour déterminer une
  convergence de synchronisation.
- **D1** : base SQL Cloudflare utilisée par les services serveur concernés.
- **Espace de données** : périmètre isolé d’un invité, profil ou compte.
- **Local-first** : l’usage local reste prioritaire et ne dépend pas du réseau.
- **Pages Function** : fonction serveur same-origin déployée avec Cloudflare
  Pages.
- **Performance Glass** : système visuel SportPilot fondé sur des tokens,
  surfaces lisibles, thèmes et mouvement maîtrisé.
- **PWA** : application web installable avec service worker et cache.
- **Snapshot social** : projection filtrée d’une activité destinée au partage.
- **Tombstone** : enregistrement durable d’une suppression synchronisée.
- **Version de calcul** : identifiant permettant de préserver le sens d’un
  résultat métier historique.
