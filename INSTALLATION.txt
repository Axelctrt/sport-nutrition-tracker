SPORTPILOT 0.25.1

Procédure de validation et publication

1. Vérifier que la branche feature/photo-ai-0.25.1 est propre et à jour.
2. Vérifier que package.json et package-lock.json indiquent 0.25.1.
3. Vérifier qu’aucun fichier .env, .env.local ou secret IA réel n’est stagé.
4. Lancer les tests ciblés IA photo.
5. Lancer npm run audit:photo-ai.
6. Lancer npm run audit:photo-nutrition.
7. Lancer npm run build.
8. Lancer npm run check.
9. Lancer npm run test:stability.
10. Tester sans endpoint IA : le fallback local doit fonctionner.
11. Tester avec proxy local Gemini : npm run dev:photo-ai-proxy.
12. Démarrer Vite avec VITE_PHOTO_NUTRITION_AI_ENDPOINT=/api/photo-nutrition/analyze.
13. Vérifier que l’analyse IA remplit le formulaire avec un résultat cohérent.
14. Vérifier que la coupure du proxy déclenche le fallback local.
15. Vérifier que Paramètres affiche la version 0.25.1.
16. Valider Open Food Facts et le scanner code-barres.
17. Committer la finalisation 0.25.1 sur feature/photo-ai-0.25.1.
18. Fusionner manuellement dans develop.
19. Relancer les contrôles release sur develop.
20. Fusionner manuellement dans main.
21. Relancer les contrôles release sur main.
22. Créer le tag annoté v0.25.1.
23. Resynchroniser develop avec main.

SportPilot 0.25.1 ne nécessite aucune migration de données.
