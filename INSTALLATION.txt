SPORTPILOT 0.23.1

PRÉPARATION

1. Vérifier que la branche feature/global-action-feedback-0.23.1 est propre et à jour.
2. Arrêter Vite avec Ctrl + C et fermer les onglets de test.
3. Exporter une sauvegarde JSON v7 récente de l’espace invité et du compte principal.
4. Vérifier que le centre de synchronisation affiche 9/9 rubriques à jour.
5. Ne supprimer aucune base IndexedDB, donnée Safari ou donnée Dexie Cloud.
6. Vérifier que .env.local, dexie-cloud.json et dexie-cloud.key restent ignorés par Git.

VALIDATION AUTOMATIQUE

7. Installer les dépendances avec npm ci.
8. Lancer npm run release:verify.
9. Lancer npm run test:e2e.
10. Lancer npm run audit:automatic-sync-release.
11. Vérifier que Paramètres affiche la version 0.23.1.
12. Vérifier l’absence d’archive, de journal et de fichier de patch dans git status.

VALIDATION DE LA SYNCHRONISATION AUTOMATIQUE

13. Activer la synchronisation automatique pour le compte courant.
14. Sélectionner Toute connexion.
15. Modifier une donnée locale puis confirmer une opération Automatique · modification locale.
16. Revenir au premier plan et confirmer une analyse sans boucle répétée.
17. Couper le réseau, modifier une donnée puis vérifier Hors connexion ou Modifications locales en attente.
18. Rétablir le réseau et vérifier Automatique · reconnexion.
19. Vérifier que la dernière réussite, le dernier échec et la source sont visibles.
20. Vérifier qu’une relance ciblée ne rejoue que les domaines en échec.

VALIDATION MULTIAPPAREILS

21. Synchroniser les deux appareils avec une base identique.
22. Créer des modifications différentes dans une même rubrique.
23. Vérifier l’apparition de l’avertissement de divergence.
24. Examiner les différences et confirmer qu’aucun remplacement silencieux n’a lieu.
25. Tester une perte réseau pendant une synchronisation et vérifier la reprise ciblée.
26. Changer de compte pendant une opération puis confirmer l’isolation stricte des historiques et états.
27. Modifier l’espace invité après déconnexion et confirmer qu’aucune synchronisation automatique ne part vers un compte.
28. Restaurer un compte puis effectuer immédiatement une modification locale.
29. Vérifier la convergence et l’absence de doublon ou de boucle d’horodatage.

VALIDATION IPHONE

30. Mettre à jour la PWA sur iPhone 15 sous iOS 26.
31. Vérifier la version 0.23.1 et le centre 9/9.
32. Tester modification locale, arrière-plan/premier plan et mode avion.
33. Vérifier la reprise réseau, l’historique et l’absence de débordement horizontal.
34. Vérifier qu’aucune tâche en arrière-plan n’est nécessaire.

PUBLICATION

35. Committer F4 sur feature/global-action-feedback-0.23.1.
36. Fusionner manuellement la branche dans main avec un commit de fusion explicite.
37. Relancer npm run release:verify sur main.
38. Pousser main puis créer le tag annoté v0.23.0.
39. Fusionner ensuite main dans develop avec un commit de synchronisation explicite.
40. Pousser develop et supprimer la branche de fonctionnalité locale et distante.
41. Vérifier le déploiement public sur ordinateur et iPhone.

VERSIONS DE DONNÉES

Runtime local cloud : sportpilot-sync-runtime-0.20.0-v10.
Schéma Dexie principal : version 8.
Sauvegarde JSON : version 7.
Registre local des espaces : version 1.

SportPilot 0.23.0 ne nécessite aucune migration de données.
