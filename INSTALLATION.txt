SPORTPILOT 0.22.0

PRÉPARATION

1. Vérifier que la branche feature/full-account-continuity-0.22.0 est propre et à jour.
2. Arrêter Vite avec Ctrl + C et fermer les onglets de test.
3. Exporter une sauvegarde JSON v7 récente de l’espace invité et du compte principal.
4. Vérifier que le centre de synchronisation affiche 9/9 rubriques à jour et 0 différence.
5. Ne supprimer aucune base IndexedDB, donnée Safari ou donnée Dexie Cloud.
6. Vérifier que .env.local, dexie-cloud.json et dexie-cloud.key restent ignorés par Git.
7. Vérifier les origines autorisées Dexie Cloud avec npx dexie-cloud whitelist.

VALIDATION AUTOMATIQUE

8. Installer les dépendances avec npm ci.
9. Lancer npm run release:verify.
10. Lancer npm run test:e2e.
11. Lancer npm run audit:full-account-continuity-release.
12. Vérifier que Paramètres affiche la version 0.22.0.
13. Vérifier l’absence d’archive, de journal et de fichier de patch dans git status.

VALIDATION DU CENTRE UNIFIÉ

14. Ouvrir Paramètres puis Synchronisation des données.
15. Lancer Analyser tout et confirmer 9/9 rubriques à jour.
16. Modifier une donnée dans plusieurs domaines, puis confirmer que seules les rubriques concernées divergent.
17. Lancer Synchroniser tout, confirmer l’opération et vérifier le retour à 0 différence.
18. Vérifier qu’un détail s’ouvre seul, se ferme et replace la vue sur Synchronisation des données.
19. Simuler une rubrique en échec et vérifier la relance ciblée sans rejouer les succès.
20. Couper le réseau, vérifier les actions cloud désactivées, puis rétablir le réseau.

VALIDATION MULTIAPPAREILS ET RESTAURATION

21. Sur le premier appareil, synchroniser le profil, les réglages, la progression et les routines.
22. Sur le second appareil, récupérer les mêmes états et confirmer 0 différence.
23. Vérifier que le mode clair ou sombre reste local à chaque appareil.
24. Créer des accomplissements différents sur les deux appareils et confirmer leur union sans perte.
25. Dans un profil navigateur vierge, détecter puis restaurer le compte depuis le cloud.
26. Vérifier les neuf rubriques après restauration.
27. Vérifier que de vraies données locales bloquent une restauration globale destructive.
28. Vérifier l’isolation complète lors d’un changement de compte.

VALIDATION IPHONE

29. Mettre à jour la PWA sur iPhone 15 sous iOS 26.
30. Vérifier la version 0.22.0 et le centre 9/9.
31. Tester une synchronisation, une restauration vierge et un retour hors ligne.
32. Vérifier la reprise réseau sans suppression ni reconnexion injustifiée.
33. Vérifier la navigation Rappels, Corbeille et Paramètres avec une seule sélection active.

PUBLICATION

34. Committer E4 sur feature/full-account-continuity-0.22.0.
35. Fusionner manuellement la branche dans main avec un commit de fusion explicite.
36. Relancer npm run release:verify sur main.
37. Pousser main puis créer le tag annoté v0.22.0.
38. Fusionner ensuite main dans develop avec un commit de synchronisation explicite.
39. Pousser develop et supprimer la branche de fonctionnalité locale et distante.
40. Vérifier le déploiement de production sur ordinateur et iPhone.

VERSIONS DE DONNÉES

Runtime Dexie Cloud : version 10.
Runtime local cloud : sportpilot-sync-runtime-0.20.0-v10.
Schéma Dexie principal : version 8.
Sauvegarde JSON : version 7.
Registre local des espaces : version 1.

E4 ne nécessite aucune migration de données. Le runtime v10 peut demander un code OTP seulement lors de sa première utilisation sur un appareil.
